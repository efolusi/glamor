# Logos

- `komando-app-icon.png`: the app icon, K-caret, 1024 × 1024 PNG with transparency. It sits on Apple's grid (an 824 body at 100,100, corner 185) with graphite `logo-ground-top` to `logo-ground-bottom`, a white top light at 10%, a white 10% inner hairline and a soft shadow, and no glow. Use it for the Dock, Finder, the website and anything outside the app, with clear space of a quarter of its width around it.
- Inside the app, draw the mark with the **AppLogo** component instead of scaling this file down.
