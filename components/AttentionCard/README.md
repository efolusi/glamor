# AttentionCard

One finding from komando's doctor, in plain words: a shape in its tone (a circle for a problem, a triangle for a warning), the finding as one sentence, what the action does on the line below in the card's tone, and one compact button. The card is tinted with its tone at 5% (`opacity-attention`) and bordered at 25% (`opacity-attention-stroke`), the same edge as a banner, so the colored sentence inside stays the loudest thing. In Swift: `AttentionCard(item: item, confirm: $confirm)`, with the words from `Finding` (`sentence`, `effect`, `action.title`).

**Provide:** the finding as one sentence that names the target ("web-1 allows root to log in with a password."), the line below it, which says what the action does ("Fix turns this off, so root can only log in with a key."), and the one action that fits. **Fix**, **Protect** and **Remove** run komando after you confirm (**PageSafetyPrompts**: "Run the fix?", "Protect staging-db?", "Remove orders-copy?"). **Add Password** opens New Secret with the name filled in (**PageNewSecret**), **Add a Host** opens the Server form (**PageNewHost**), **View** opens the target's tab, and **How to Fix** opens a sheet for a change komando can't make for you (**PageHowToFix**).

- **Severity by shape and color, with a word.** A problem (a failed check) is `exclamationmark.circle.fill` in `danger`; a warning is `exclamationmark.triangle.fill` in `warn`, both 16 at the card's leading edge. Color alone can't carry it: `warn` and `danger` are 1.00:1 to each other in light. VoiceOver reads the mark as "Problem" or "Warning", and the card is one element (`.accessibilityElement(children: .combine)`): "Problem. prod-db's password is missing from the keychain. komando can't connect…" On iPhone and iPad, `FindingRow` uses the same two shapes and words (UX audit P1-6).
- The tone is `danger` for a failed check and `warn` for a warning. No category, no check name (`host:web-1`) and no Copy Fix: the sentence says what is wrong.
- Full width, `space-16` apart, failures first: up to two on Home with "View all 4" (**PageDashboard**), every one on the Findings tab (**PageDoctor**).
- One button, compact secondary. There is no Ask the Agent button: the agent drawer (⌘J) already knows komando's findings.
- After a change, a success **Banner** above the page says "Done. web-1 is fixed; the finding clears on the next check."; if komando stops it for safety, it asks once in **PageSafetyPrompts**; any other error is a danger **Banner** with komando's hint.
