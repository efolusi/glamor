# CommandPalette

⌘K over everything. Type to find a target or a place, or `user@address` to connect, then press Return. In Swift: `CommandPalette()`, shown as an overlay on `RootView`.

**Provide:** nothing. It lists targets (recent first), then the actions, then places, at most 12 at a time. The actions are **Add…** (`plus`, "A server, database, cache, storage, cluster, registry, queue or VPN": it opens **PageAdd**, the one chooser for every kind and every importer, and replaces New Host, New Connection and Import from SSH Config), **Run a Command…** (`terminal`, which replaced the Console place), **New Forward…** and **All Findings**. With the field empty it shows up to five targets, the first three actions, then the places. Typing `user@address` offers Connect to it, first; typing anything else also offers "Run komando …" with the words, last.

- **Run a Command…** with nothing typed keeps the palette open, shows a **Run on** field (**TargetsField**, owner decision 2026-11-17, M-MV5) under the search field, opened on the target the page shows. With targets in it, the field asks for the command for those servers ("Type the command, for example uptime"), and Return runs `komando exec @web -- COMMAND` in its own terminal tab, titled with the command; the row says "Run on @web". With Run on empty, the field takes any komando command as before ("Type a komando command, for example status"). A command typed straight away runs the same way from the "Run komando …" row.
- **Workspaces (gap M17).** **Save Workspace…** (`square.stack`, "Keep the open tabs and splits under a name") keeps the palette open and asks for the name in the field, like Run a Command… ("Name the workspace, for example deploy"); Return on "Save Workspace NAME" saves it, and a name in use asks "Replace the workspace NAME?" first in an **AlertDialog**. Each saved one is then a row **Open Workspace NAME** (`square.stack`, "N tabs"), found by typing its name: it opens the same targets (on the same underline tab), terminal sessions (same command, same title, the same panes in the same rows) and Files tabs, beside what is open. Its right-click (in the palette's row) offers **Delete Workspace**. Workspaces live in the app's settings on this Mac; komando keeps none.
- The palette is `palette-width` (620), 88 from the top, on `panel` with `radius-16` and `shadow-palette`, over a `scrim`.
- The input row is 56 high with `input-l`, its placeholder naming all three uses: "Find a target or place, connect to user@address, or type a komando command". Rows are 40 high with a 28 tile, the title in `text` and the detail in `text3`, on the **ListRow** spec: 8 in from the palette's edge, 2 apart, the tile 12 inside the highlight. The chosen row is `subtle` with ↩.
- ↑ and ↓ move the selection, Return runs it, and esc or a click outside closes the palette.

- Motion: none (frequent). The palette opens and closes at once, and ↑ ↓ move the selection at once.
