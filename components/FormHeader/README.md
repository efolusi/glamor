# FormHeader

The top of a form: a 48 icon tile, the form's title in `title-l`, and one line saying what is being added. In Swift: `FormHeader(symbol: "server.rack", tint: Family.servers.tint, title: "New Host", subtitle: "A server you reach over SSH")`.

**Provide:** the symbol and tint of what the form creates, a Title Case title, and a one-line subtitle.
