# AlertDialog

A confirmation in Komando's sizes: 260 wide, the 48 logo, the title in `body-strong`, the message in `caption`, and full-width 32 buttons. In Swift, the system `.alert`, which draws the same parts.

**Provide:** a title that names the risk, a message with the exact command or flag, and buttons that say what happens: the action first (destructive in `danger`), then Cancel.

- Motion: none of our own. The system's alert motion.
