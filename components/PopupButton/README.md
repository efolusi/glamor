# PopupButton

A menu picker drawn as a field: 32 high (28 compact), the value on the left, `chevron.up.chevron.down` at 12 on the right. In Swift, `Picker(…).pickerStyle(.menu)` inside the field style.

**Provide:** the value (or a placeholder such as "Choose…"), an optional symbol and its tint, and `size: 'sm'` for toolbars and side panels.

- Use it for one choice out of a list that does not fit in a **Segmented** control: the server a forward goes through, the audit log range, a database schema.
