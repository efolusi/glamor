# Checkbox

A checkbox with its label: 16 square, `radius-4`, `accent` when on, 8 to the label in `caption`. In Swift, `Toggle(…).toggleStyle(.checkbox)`.

**Provide:** the label and the state.

- Use it for options that change how a command runs (Read-only, Dry run, Allow writes), in a row under the command bar or in a toolbar.
- Give each one a `.help` that says what it changes.
