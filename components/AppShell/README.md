# AppShell

The window every screen sits in: the sidebar on `window` and the floating `panel` with its header. In Swift it is `RootView` with `Sidebar()` and `PanelHeader()`.

**Provide:** `place` (the selected place, or none when a tab is in front), `tabs` and `activeTab` for open things, `action` for the page's one create button (drawn at the right of the panel header), `flush` for full-bleed content (toolbars, panes, terminals), and the content.

- **Sidebar, top to bottom:** the window buttons, with **Hide Sidebar** (`sidebar.left`, a ghost `xs` in `text3`, tooltip "Hide the sidebar (⌃⌘S)") at the right of their row; the logo and "Komando", nothing else (no status dot: a dot nobody can read helped no one, and komando not answering already shows as a `danger` **Banner** on the page; the komando version is in the profile menu); Search (⌘K, no badge); six places (Home, Hosts, Connections, Files, Port Forwarding, Recipes; ⌘1 to ⌘6), where Files shows the number of running transfers in `accent` (`transfers`, **SidebarItem**); **More**, closed until one of its places (Jobs, Keychain, Audit Log) is chosen; and the profile row (**ProfileCard**): clicking it opens the profile menu, which carries the komando version ("komando 1.4.0 · 21 targets", or "komando is not answering"); the row shows no plan, because the apps are free. Nothing else: no create button, no groups, no license card.
- **The sidebar can be resized and hidden** (owner decision 2026-11-14). Its trailing edge is a **SplitDivider** without a hairline (the sidebar sits on `window`): the 4-wide grip shows under the pointer. 256 by default (`sidebar-width`), 200 to 320, snapping to 4; a double-click puts it back to 256. Dragged under 200 it hides, as **Hide Sidebar** and View › Hide Sidebar (⌃⌘S) do. Hidden, the panel gets `window-inset` on its left too, the window buttons sit in the panel header's left end, and **Show Sidebar** (`sidebar.left`) follows them. The width and whether it is hidden are remembered for the whole app, so every window opens the same way. The window's least width is the live sidebar width plus the 760 page minimum plus the insets, not a fixed 1040.
- **Header** (**PanelHeader**): the title or the open tabs, then the agent (`text.bubble`, ⌘J), refresh, and `action` as the one primary: **Add** (⌘N) on Hosts and Connections, New Forward, New Recipe, New Secret; none on Home.
- **Tabs inside a target** (`DetailTab`): Overview first, at most six tabs. A host gets Overview · Services · Logs · Updates · Containers (only when the host has Docker) · Terminal. A database gets Overview · Query · Backups. A cache gets Overview · Keys. Every other kind has Overview only. Per-server work lives in its server's tabs, never in a new sidebar place: the Mac sidebar stays six places and More. A host's files are the exception that proves it: Files is a place of its own because a pane can hold any server or storage, and Files in a host's menu opens that place with the host in the right pane. Backups is still to draw (**PageDatabaseBackups**).
- **iPad and iPhone** have five places: Home, Targets, Recipes, Agent, Settings. Files is not a place there: it opens from **Browse Files** on a server's or storage's detail (**PageiPhoneFiles**, owner decision 2026-11-14). Recipes is still to draw (**PageiPadRecipes**). On the phone a server's Services, Logs and Updates only read; a restart, an upgrade or a reboot goes through the Agent's approval card.
- Without `flush`, content sits in the page padding (`space-24` top and bottom, `space-32` at the sides); with it, the content owns the panel edge to edge.
- Places that no longer exist map to where their content went: Dashboard and Doctor to Home, VPNs to Connections; Console became ⌘K → Run a Command…; Agent became the ⌘J drawer.
- **Proposed (Komando Cloud, nothing built).** Signing in adds nothing to the sidebar: it stays six places and More. The profile menu gains **Account…** (**PageAccount**) and **Team…** (**PageTeam**), and Settings gains Account and Team tabs.
- **Empty.** The preview shows Hosts with no hosts while two transfers run (the Files count): an **EmptyState** "No hosts yet", "Add a server you reach over SSH with Add, or import the ones in ~/.ssh/config.", and **Import from ~/.ssh/config** (secondary, **ImportSheet**) under it, so Add stays the one primary.

## Menus

The window's menus in the Mac menu bar (Komando, File, View, Terminal, Go, Help, `AppCommands`) are drawn on **PageAppMenus**, the one place every shortcut is written out. File holds the one **Add…** (⌘N, as the header has one Add; no New Host, New Connection or ⇧⌘N), and Terminal holds **Split Right** (⌘D) and **Split Down** (⇧⌘D). A page's own shortcuts stay in its buttons' tooltips: Run (⌘↩), Test (⇧⌘T), Save (⌘↩). Files keeps Finder's keys: ⌘↑ goes up one folder, ⌥⌘→ and ⌥⌘← copy to the other side (**PageFiles**).
