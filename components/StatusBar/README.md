# StatusBar

The 28-high line under a terminal, a query or a key browser, in `caption` on `panel` with a `border` rule above.

**Provide:** facts on the left (terminal type, row count and time, server version) and the facts that reassure on the right (that commands go to the audit log, how the session is signed in, the transaction mode).

- Keep it to facts. Actions belong in the toolbar above the content.
