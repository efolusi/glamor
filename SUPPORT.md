# Support

- **Usage questions:** GitHub Discussions when enabled, otherwise an issue. Read `README.md`, `guidelines/overview.md`, and `guidelines/ecosystem.md` first.
- **Bugs:** Open an issue with a preview card path or Swift file and steps to reproduce.
- **Shared tokens with Meridian:** Propose the change in [design-tokens](https://github.com/efolusi/design-tokens).
- **Security:** Never a public issue. See [SECURITY.md](SECURITY.md).

No paid support or SLA. Maintainers review issues when they can; reports with a clear reproduction get answered first.
